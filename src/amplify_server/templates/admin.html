Pod pytest arguments loading
The pytest options every Grid run passes to the runner pods, and the values users may pick for them in the Grid tab's New run form. Run's environment is a dropdown of its values (the environment names, which the coordinator's SUPPORTED_ENVIRONMENTS must include): the choice is the run's environment (TEST_ENV on the pods, the Runs list) and this option's value (e.g. --env qa3); Pick from values becomes a dropdown (values separated by commas); On/off switch passes the bare option when ticked. The options must exist in the test repo (its conftest.py or a plugin) or pytest stops with "unrecognized arguments". Applies to every user.
